### What's New in Oto v1.2.4:
- **Listening History & Data Restored**: Non-destructively restored and merged all listening history events, playlists, liked tracks, and music metadata from legacy databases (`mochy.db` to `oto.db`).
- **Zero-Loss Database Engine**: Replaced destructive file overwrites with transactional SQLite merging so future updates never reset or regress listening stats.
- **Local Folder-Centric Audio**: Pure music directory selection via system folder picker, indexing only chosen music folders.
- **System Performance Overhaul**: Lightweight, responsive UI across all screens with native SQLite WAL optimizations.
